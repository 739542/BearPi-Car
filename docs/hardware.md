# 实验器材与接线

这辆车由左右两个驱动轮和底盘支撑轮组成。车上只需一块 BearPi 主板即可承担 Wi-Fi 热点、网页服务和电机控制。为语音遥控准备的第二块板可以放在操作者手中。

| 器材 | 数量与规格 | 在实验中的用途 |
| --- | --- | --- |
| BearPi-HM Nano | 车端 1 块，Hi3861；手持语音端方案另用 1 块 | 车端运行 v11；手持端留给语音成员开发 |
| DFRobot MiniQ ROB0049 桌面机器人底盘 | 1 套，直径约 122 mm，配两只 42 mm 轮、两只直流减速电机、支撑件及紧固件 | 左右轮差速转弯。电机已包含在套件中 |
| DFRobot DRI0044 | 1 块，TB6612FNG 双路直流驱动，排针已焊 | 接收两路方向和两路 PWM，独立给电机供电 |
| 电池盒与 AA 电池 | 1 个四节串联五号电池盒，带盖、杜邦母头；同类型 AA 电池 4 节 | 电机电源。四节 1.5 V 电池标称共 6 V；若用 1.2 V 镍氢则为 4.8 V |
| USB 供电与数据线 | 车端 USB Type-C 数据线 1 根；手持板启用时另配 1 根 | 电脑供电、烧录和串口调试。移动时可用有稳定 5 V USB 输出的电源。锂电替代方案尚待选型 |
| 电机转接线 | PH2.0 双针转 2.54 mm 杜邦母头，每个电机 1 条 | 插入电机插座及驱动板输出排针 |
| 杜邦线 | 2.54 mm，约 20 cm，三种端头组合 1 包 | BearPi 排母与驱动板排针之间用公对母线，控制侧共 6 路 |
| 固定材料 | 尼龙扎带、泡棉双面胶、底盘配套螺丝 | 固定电池盒、理线，轮轴两侧留出转动空间 |
| 离线语音模块及线束 | DFRobot Gravity SEN0539，实物 DF2301QG V1.0，1 块；Gravity 4P I²C/UART 线 1 根 | 已到手。双麦克风识别命令，识别结果由 BearPi 读取；接入方法见语音交接 |
| 操作与调试设备 | Windows 电脑、Ubuntu SDK 虚拟机、带 Wi-Fi 和浏览器的手机各 1；装配用小十字螺丝刀 | 编译、HiBurn 烧录、网页双指操作。万用表可用于确认极性 |

## 车端逐针连接

| DRI0044 丝印 | 另一端 | 作用 |
| --- | --- | --- |
| DIR1 / PWM1 | IO10 / IO07 | M1 左轮的方向和占空比 |
| DIR2 / PWM2 | IO12 / IO08 | M2 右轮的方向和占空比 |
| VCC / 控制侧 GND | BearPi V3.3 / GND | 逻辑供电和信号参考 |
| VM / 电源侧 GND | AA 电池盒正极 / 负极 | 电机电源，只接驱动板电源侧 |
| M1+、M1− | 左电机两端 | 面向车头判别左右 |
| M2+、M2− | 右电机两端 | 当前实车接法中，两路方向脚低电平均对应前进 |

接线或移动电源插头前断开 USB 与电机电池。先通过串口确认上电停车，再分别执行半秒左轮、右轮测试。模块照片中的红黑线应按两端丝印核对，尤其注意主板右侧相邻的 GND、V3.3 与 V5.0。
